========================================
Sprint 2 - Digital Asset Authentication
========================================

Assets

POST /api/assets/upload
- Upload an image.
- Automatically:
  - Store file
  - Generate SHA-256
  - Generate pHash
  - Extract metadata
  - Save asset
- Status: implemented

POST /api/assets/check
- Temporarily process a JPG, PNG, or WebP image without registering it.
- Requires JWT authentication.
- Checks exact SHA-256 matches first, then finds the closest stored perceptual hash using bit-level Hamming distance.
- Perceptual responses include similarity classification, distance, applicable threshold, and hash bit length.
- Deletes the temporary upload after processing.
- Returns full asset identity only for the authenticated owner; cross-owner matches use pseudonymous owner and asset references.
- Status: implemented

GET /api/assets
- List authenticated user's assets.
- Owner-scoped and newest-first.
- Status: implemented

GET /api/assets/:id
- Return asset details.
- Enforces authenticated ownership.
- Status: implemented

GET /api/assets/:id/content
- Return the stored image for an owned asset.
- Requires JWT authentication and enforces ownership.
- Status: implemented

DELETE /api/assets/:id
- Delete asset.
- Status: planned

GET /api/assets/:id/hash
- Return SHA-256 and pHash.
- Enforces authenticated ownership.
- Status: implemented

GET /api/assets/:id/metadata
- Return extracted metadata.
- Enforces authenticated ownership.
- Status: implemented

Verification

POST /api/verifications
- Compare a temporary image against one selected asset owned by the authenticated user.
- Requires JWT authentication and multipart fields `assetId` and `file`.
- Produces exact, strong visual, possible visual, or no meaningful match evidence.
- Saves thresholds, pHash distance, safe metadata differences, and report timestamps without storing the comparison image.
- Status: implemented

GET /api/verifications
- Return only the authenticated user's verification history, newest first.
- Status: implemented

GET /api/verifications/:reference
- Return one owner-scoped report by its pseudonymous VR reference.
- Status: implemented
